# flowertalker — золотое поле

Личная страничка в духе strawpage: 3D-поле золотых калифорнийских маков (привет Сан-Франциско и мосту Золотые Ворота на горизонте), рассказанное скроллом от утра до ночи.

## Что происходит при прокрутке

1. **Утро** — на глазах раскрывается большой золотой цветок, вокруг прорастает поле.
2. **Знакомство** — камера отъезжает и показывает всё поле.
3. **Грядки** — камера идёт сквозь цветы, карточки-увлечения едут вбок (на телефоне листаются пальцем).
4. **Доска** — виджеты «сейчас играет / читаю / настроение» и стикеры, которые можно перетаскивать.
5. **Закат** — цитата проявляется по словам.
6. **Ночь** — звёзды, луна, светлячки. Клик по земле сажает золотой цветок (сохраняется в браузере гостя).

Цветы качаются на ветру и отклоняются от курсора. Часы в шапке идут вместе со скроллом. Учтён `prefers-reduced-motion`.

## Как поменять тексты

Всё про тебя лежит в [`src/content.js`](src/content.js): имя, увлечения, виджеты, цитата, ссылки.

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга (GitHub Pages, Netlify, Vercel — любой статический):

```bash
npm run build
```

Готовый сайт окажется в папке `dist/`.

## Устройство

- `src/scene.js` — Three.js: поле (инстансы травы и маков, ветер в шейдере), небо со сменой времени суток, главный цветок, пыльца и светлячки, маршрут камеры.
- `src/main.js` — Lenis (плавный скролл) + GSAP ScrollTrigger: связывает главы с маршрутом камеры.
- `src/ui.js` — разметка из `content.js`, перетаскиваемые стикеры.
- `src/style.css` — оформление.
